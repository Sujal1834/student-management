# 🎓 Student Management System

A full-stack **Student Management System** designed to manage students, faculty, courses, attendance, quizzes, and academic records efficiently.  
This project is built as part of academic learning using modern web technologies.

---

## 🚀 Features

### 👩‍🎓 Student Module
- Student registration & login
- View profile and academic details
- Attendance tracking
- Quiz participation
- View results and performance

### 👨‍🏫 Faculty Module
- Faculty authentication
- Manage students and courses
- Mark and manage attendance
- Create and manage quizzes
- View student performance

---

## 🧰 Tech Stack

### Frontend
- React.js
- TypeScript
- Formik & Yup (form handling & validation)
- Axios (API communication)
- CSS / Modern UI

### Backend
- Django
- Django REST Framework (DRF)
- JWT Authentication
- PostgreSQL
